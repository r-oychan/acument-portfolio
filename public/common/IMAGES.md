# Common — shared imagery

Generic fallback illustrations used when a case study doesn't yet have
bespoke assets. Served at `/acument-portfolio/common/<file>`.

## Current assets

- `laptop-hero-image.png` — 16:9 watercolor desk scene with a laptop and
  potted plant. Generic hero fallback for any case study.
- `power-platform.png` — 1:1 watercolor of Power Platform app tiles.
  Generic inline figure for any Power Platform-led engagement.

## Style anchor

Soft watercolor, pastel palette, flat (0px radius, no shadow), no real IP.
